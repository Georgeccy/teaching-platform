**写作主要问题 💡**
- although...so 连用（最常见）：although 后不加 so，保留一个。
- 动名词作主语：be a volunteer→being a volunteer。
- 固定搭配：share...with、the best way for me to relax。

**写作提升建议**
1. although / so 不能连用（最重要）。
2. 动名词作主语 + share...with 搭配。
3. 保留内容、词汇、连接词优势。
