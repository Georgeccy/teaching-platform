## 三、存在的不足

- **写作语法错误密集（15+ 处），句子破碎影响理解**：will + 原形（will smoking → will smoke）、be 动词（People after smoking will very excited → will be very excited）、because of + 名词（because of following → because of trends）、主谓一致（some student get → some students get）、拼写（healthly → healthy）。
- **写作段内无连接词**：三段都缺乏 First / Moreover / Therefore，句子并列堆叠，读起来像清单。
- **阅读总结填空 Q56 全错（-4）**：没通读 paragraph 3 就凭印象作答。
- **阅读开放简答答非所问（约 -7）**：Q62 问"为什么 SARS 容易传播"，答"有防病措施"；Q66 应写 poor governance + foreign exploitation，写的是"社会不平等"。

## 四、改进建议

1. **写作**：主攻"基础语法自检清单"——will + 原形、be 动词、because of + 名词、主谓一致；每段加 First / Moreover / Therefore 等连接词，让段落从"清单"变"文章"。
2. **阅读**：总结填空先通读全段再定位；开放简答"问什么答什么"（Q62 答案就是 airborne）。
3. **保持**：内容构思和定位找词是优势，语法和连接词补上后，内容优势才能变现。
